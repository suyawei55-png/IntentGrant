# bindings

Transport bindings for IntentGrant profiles.

- `mcp/` — IG-MCP binding (interface definition, v0.2): **to be added**. The IG-MCP
  interface document is an independent normative document, not an implementation.
  Protocol semantics and the pseudocode reference live under `profiles/lite/`.

Bindings define how profile evidence is carried over a given transport. They are
specification documents only — nothing in this directory is executable code.
